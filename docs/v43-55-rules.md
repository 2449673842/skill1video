# Attention V4.3 — 55 条硬规则执行契约

> 目标：不是让画面一直动，而是让观众追着一个有意义的对象，看懂一个正在发生的变化。  
> 优先级：叙事连续性 > 注意力引导 > 阅读理解 > 静动节奏 > 动效复杂度 > 炫酷程度。

## 55 条硬规则

1. 禁止 PPT 感：不能以“场景 A 出现→淡出→场景 B 重新出现”作为主要叙事方式。
2. 每个主要边界必须明确上一镜留下来的对象或视觉关系。
3. 上一幕主体应优先成为下一幕入口或主体。
4. 禁止统一光球、光点、圆环、闪光、粒子团承担全片转场。
5. 转场不能只是覆盖层，必须继承或改变真实场景对象。
6. 转场必须有视觉因果。
7. 跨边界运动应继承方向、位置、速度趋势或空间关系。
8. 转场数量由叙事决定，不固定“四个大转场”等模板。
9. 转场时长不统一，由动作所需时间决定。
10. 节奏不是定时器，禁止固定几秒动一次、缩放一次、震一下。
11. 必须允许真正静止，阅读段禁止持续微缩放、漂移、震动。
12. 禁止为了动而动；无叙事、注意力或物理意义的动作删除。
13. 静与动必须形成反差：静→动→加速→停→阅读→爆发→回落。
14. 高潮前要有准备。
15. 高潮后要有稳定和余韵。
16. 镜头跟主体关系走，不随机推拉摇移。
17. 焦点接力：先改变视觉层级，再决定是否运镜。
18. 主体已经足够运动时，相机应稳定。
19. 禁止长期把整个 scene container 平移/缩放/抖动冒充镜头设计。
20. 画面需要主主体、关系对象和必要空间环境，避免长期“背景+中央大字”。
21. 高信息密度不等于高元素密度，同一时间必须有明确主焦点。
22. 禁止为了不空而填无意义装饰。
23. 需要时使用前中后景、视差、遮挡、尺度差建立空间。
24. 数字必须经历真实变化过程，不能直接跳到结果。
25. 数字达到关键值时反馈应克制且有语义。
26. 图表必须按叙事逐步建立。
27. 图表先成形，再补标签、单位和结论。
28. 动画对象必须保持可追踪身份。
29. 复杂变化要分阶段，不能只靠 opacity + scale。
30. 物理语言必须多样，不能全片同一种 ease / slide / zoom。
31. 动效多样性必须由内容驱动，不为炫技而炫技。
32. 字幕属于画面，可参与情绪，但服从语义。
33. 正文阅读阶段必须稳定。
34. 禁止所有字幕统一动画。
35. 文字不是画面的替代品，抽象语言尽量转成关系、对象和过程。
36. 声音、画面和动作共用叙事节奏。
37. 声音需要留白，安静也是设计。
38. 禁止拿音乐节拍绑架画面。
39. 参考 HTML 必须学习运动逻辑，不只学配色和排版。
40. HTML 的“动作→停住→阅读→再动作”要抽象成规则，而非复制图形。
41. 参考视频学习对象关系和焦点逻辑，不只复制表面特效。
42. 复杂画面按注意力顺序逐步建立，不能一次全摆出来。
43. 每个非刻意静止镜头必须有一个明确“当前事件”。
44. 关键帧必须覆盖前态、触发、峰值、重组、结果。
45. 转场检查必须看边界前、中、后连续帧。
46. 必须检查完整成片，不能只看源码或编译通过。
47. 必须从最终编码 MP4 重新抽帧。
48. 自动指标不能代替“看起来是否自然”的人工判断。
49. 用户指出“生硬/PPT/盖特效”即视为视觉失败。
50. 用户指出“为了节奏而节奏”即视为失败。
51. 过密时优先做减法，不用更多特效掩盖问题。
52. 任意时刻必须能回答：观众现在看什么、为什么、下一秒谁接走注意力。
53. 全片要像一次连续思考，而不是多个漂亮但孤立的小场景。
54. 优先级：叙事连续性 > 注意力引导 > 阅读理解 > 静动节奏 > 动效复杂度 > 炫酷程度。
55. 每个动作都要通过删除测试：删掉不损害理解/情绪/注意力/连续性的动作，原则上删除。

## P0 硬失败规则

以下规则一旦违反，不允许把版本标记为通过：1、3、5、10、11、16、24、26、39、45、49、50、54、55。

## V4.3 对应实现

- 时间轴：不再使用固定 8 秒 scene grid；按语义使用不等长区间和重叠边界。
- 静止区：在 5.8–7.4、17.6–19.2、28.3–31.2、39.9–41.5、50.8–53.2、63.2–65.7、76.2–78.2、88–91、98.7–100.4、107–108.8、113.6–116、118.7–120 秒设置主动低运动/静止期。
- 对象链：信息卡→筛选门→人物焦点→搜索关系→工作卡→工作区→网络→轨道→分叉→矩阵单元→纸页→时间块→枝干。
- 无统一 overlay carrier：连续对象直接由同一全局组件跨段保持。
- 镜头：默认锁定；只在网络连接段做一次轻微揭示。
- 声音：事件驱动，不在固定边界打点；quiet windows 真实降低声部密度。
- 工作流：先生成关键窗口和导演证明帧，再完整渲染；最终从 MP4 再抽帧做 contact sheet。
